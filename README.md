# LUMORA-Salon
1. Project Overview

LUMORA Salon is a responsive, interactive salon and beauty-service website designed to provide users with information about salon services, offers, team members, locations, and appointment booking.

The website includes a modern landing page with sections for Hair Studio, Skin & Glow, Bridal & Makeup, and Men's Grooming services. It also provides location selection for cities such as Hyderabad, Kakinada, Vijayawada, Visakhapatnam, and Rajahmundry.

The project also includes interactive appointment booking and contact forms using JavaScript. Users can select a service, city, date, and time when submitting an appointment request.

2. Learning Objectives

The main learning objectives of this project are:

Learn how to build a responsive website using HTML, CSS, and JavaScript.
Understand how to structure a multi-section business website.
Create reusable UI components such as service cards, offer cards, team cards, and location cards.
Implement interactive forms and popup/modal interfaces.
Learn JavaScript DOM manipulation and event handling.
Implement dynamic city/location selection.
Understand responsive web design using CSS media queries.
Improve UI/UX design skills through typography, layouts, spacing, buttons, cards, and navigation.
Learn how to organize a front-end project into separate HTML, CSS, and JavaScript files.

4. Methodology

The project was developed using a front-end web development methodology consisting of the following stages:

Step 1 — Requirement Analysis

Identify the main requirements of a salon website, including:

Services
Offers
Locations
Team information
Contact details
Appointment booking
Step 2 — Website Structure

The website was structured using semantic HTML sections such as:

Header/navigation
Hero section
City selector
Services
Offers
Social timeline
Team
Locations
Contact
Footer
Booking modal

The navigation provides access to these major sections and includes a Book Now action.

Step 3 — UI Design

CSS was used to create a modern salon-oriented visual design with:

Typography
Color schemes
Cards
Buttons
Grid layouts
Hover effects
Hero imagery
Responsive layouts

For example, service cards have hover effects that move the card upward and add a shadow.

Step 4 — Interactivity

JavaScript was implemented to make the website interactive.

For example, selecting a city dynamically updates the displayed city and address.

The booking modal can also automatically select a service when the user clicks Book Service.

Step 5 — Responsive Design

Media queries were added to adapt the website for different screen sizes. On smaller screens, multi-column layouts become single-column or two-column layouts.

Step 6 — Testing

The website can be tested in a browser for:

Navigation
City selection
Service booking
Contact form
Responsive layout
Mobile compatibility
Modal opening/closing
5. Dataset Source

Dataset: Not Applicable (N/A)

This project is a front-end website development project, not a machine-learning or data-analysis project. Therefore, it does not use a traditional dataset.

The website uses static/sample business information such as salon services, prices, locations, offers, and team details directly within the HTML and JavaScript files. For example, city information is stored in the JavaScript cityData object.
